Adaptations in the adjacent `.glsl` files:

- Remove Odin-specific `@header package` and `@header import` directives.
- Remove the Odin `@ctype mat4 matrix[4,4]f32` mapping; the C generator's
  default `float[16]` matrix representation is used.
- Rename uniform blocks from `vs_params` to `tilemap_params` and
  `sprite_params`, respectively, avoiding C binding collisions with each other
  and the triangle shader.
- Preserve module/program names, shader stages, and all GLSL rendering logic,
  including input types, bindings, flip transforms, lookup decoding, repeat,
  discard, opacity, and additive-color behavior.

`render2d.c` ports the two Odin pipeline setups into C, without the ECS/world,
decoders or director. It shares quad geometry, uses explicit `offsetof`/stride
layouts, a scalar uint32 flip attribute matching the shader's `uint`, nearest
clamped sampling, and explicit resource ownership/cleanup (including shaders).
Culling is disabled to support either quad orientation. The C camera maps a
portable 0..1 sprite depth range to each backend's clip-depth range. `main.c` creates new
procedural RGBA8 fixtures; no original artwork or packed resources are imported.

Adjacent `.glsl.h` files are generated by `make shaders` using the repository's
Sokol shader compiler with `-f sokol -l glsl300es:metal_macos`; they are not
hand-edited. `SOURCE.json` remains unchanged and records earlier imports only.
